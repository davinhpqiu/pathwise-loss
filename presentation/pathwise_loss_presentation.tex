\begin{frame}{Path closeness in continuous time}
\textbf{Role of discretisation}\par
  Most time series models are sequence-to-sequence and trained with pointwise losses such as mean squared error (MSE). Neural differential equations enable path-to-path learning, where inputs and outputs are continuous-time trajectories. An open question is which loss functions are best suited to path-to-path learning, as previous work has shown that pointwise objectives can overfit local noise and fail to capture temporal structure (Ramsay and Silverman, 2005; Kudrat et al., 2025). 
  \source{Project proposal and Notebook 01, Sections 2 and 3}
\end{frame}

\begin{frame}{Path closeness in continuous time}
  \textbf{Project question}\par
  The project studies definitions of path closeness and how each definition changes the learned path or operator.
  Suppose two predictions agree with a target at every recorded time:
  \[
    \widehat Y_A(t_j)=\widehat Y_B(t_j)=Y(t_j),
    \qquad j=0,\ldots,m.
  \]
  Pointwise MSE gives both predictions zero loss. Their behaviour between observations can still differ, so
  \[
    \int_0^T\|\widehat Y_A(t)-Y(t)\|_2^2\,dt
    \neq
    \int_0^T\|\widehat Y_B(t)-Y(t)\|_2^2\,dt.
  \]

  \textbf{Role of discretisation}\par
  Although paths are stored at finitely many times, the loss still determines how the underlying paths are compared. Weighting, interpolation and feature representation each affect that comparison.
  
  \source{Project proposal and Notebook 01, Sections 2 and 3}
\end{frame}

\begin{frame}{Path-to-path learning}
  A model maps one evolving object to another. Input path $X^{(i)}:[0,T]\to\mathbb R^{d_x}$ is an observed driver or stream, and predicted response is
  \[
    \widehat Y^{(i)}_\theta=\mathcal F_\theta\!\left(X^{(i)}\right).
  \]
  Training uses paired input and target paths $(X^{(i)},Y^{(i)})$ and selects
  \[
    \widehat\theta=\arg\min_\theta
    \frac1N\sum_{i=1}^{N}
    \mathcal L\!\left(\widehat Y^{(i)}_\theta,Y^{(i)}\right).
  \]

  \vfill
  Discrepancy $\mathcal L$ decides which prediction errors training treats as large. Every experiment below changes $\mathcal L$ and holds everything else fixed.
  \source{Project proposal. Functional path viewpoint: Ramsay and Silverman (2005) [1]}
\end{frame}

\begin{frame}{Observation density and the sampled loss}
  Let observation times have density $q$ on $[0,T]$ and let
  $e_\theta(t)=\widehat Y_\theta(t)-Y(t)$. Then
  \[
    \frac1m\sum_{j=1}^{m}\|e_\theta(t_j)\|_2^2
    \longrightarrow
    \int_0^T \|e_\theta(t)\|_2^2 q(t)\,dt.
  \]
  Trapezoidal elapsed-time weights instead approximate
  \[
    \Jtwo(\theta)=\int_0^T \|e_\theta(t)\|_2^2\,dt.
  \]
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.47\textwidth}
      \textbf{Uniform observations}\par
      $q$ is constant. MSE and $\Jtwo$ differ mainly through endpoint weights.
    \end{column}
    \begin{column}{0.47\textwidth}
      \textbf{Clustered observations}\par
      MSE rewards accuracy where points are dense. $\Jtwo$ restores elapsed-time emphasis.
    \end{column}
  \end{columns}
  \source{Derivation and assumptions: Notebook 01, Sections 2 and 3}
\end{frame}

\begin{frame}{Order and integral norms}
  Every $L^p$ discrepancy compares residual magnitude at aligned times, so it depends on the path only through how long the residual spends at each size. Any measure-preserving rearrangement of time leaves it unchanged:
  \[
    \|f\|_{L^p}\ \text{depends on}\ f\ \text{only through}\
    \mu_f(\lambda)=\left|\{t:|f(t)|>\lambda\}\right|.
  \]
  Permuting when events happen is acceptable in a norm and disqualifying in a path-to-path loss, where order is the structure being learned.

  \vfill
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.47\textwidth}
      \textbf{Consequence for rough streams}\par
      A second-level perturbation can leave every coordinate value unchanged. Coordinate losses then respond by exactly zero, whatever their exponent or weighting.
    \end{column}
    \begin{column}{0.47\textwidth}
      \textbf{What signatures add}\par
      Level $k$ is an iterated integral over $t_1<\cdots<t_k$, so it is built from ordering rather than from magnitude at aligned times.
    \end{column}
  \end{columns}
  \source{Rearrangement invariance: Notebook 01, Section 3.3. Layer cake representation: Lieb and Loss (2001) [13]}
\end{frame}

\begin{frame}{Four loss families}
  \small
  \begin{tabular}{>{\bfseries}p{0.18\textwidth}p{0.34\textwidth}p{0.385\textwidth}}
    \toprule
    Loss & Definition & Emphasis \\
    \midrule
    Pointwise MSE & $\displaystyle \frac1m\sum_{j=1}^{m}\|\widehat Y(t_j)-Y(t_j)\|_2^2$ & Each recorded point has equal weight \\
    Elapsed-time $\Jtwo$ & $\displaystyle \int_0^T\|\widehat Y(t)-Y(t)\|_2^2\,dt$ & Error accumulated over time \\
    Sobolev $H^1$ & $\displaystyle \Jtwo+\kappa\int_0^T\|\dot{\widehat Y}(t)-\dot Y(t)\|_2^2\,dt$ & Values and local velocity for smooth paths \\
    Signature loss & $\displaystyle \|\Phi(\widehat Y)-\Phi(Y)\|_2^2$ & Ordered increments and interactions \\
    \bottomrule
  \end{tabular}

  \vfill
  \textbf{Comparison principle}\par
  Weight $\kappa>0$ balances value against velocity error; $\Phi$ is a truncated signature feature map, defined on the signature slide. Train a matched model under each objective, then evaluate every fitted path under every metric.
  \source{Integral and Sobolev norms: [1]. Signatures and rough paths: [2,3,8]}
\end{frame}

\begin{frame}{Signatures}
  For a path $Y:[a,b]\to\mathbb R^d$, its depth-$M$ truncated signature is
  \[
    S^{\le M}(Y)_{a,b}
    =\left(1,\int_a^b dY,
    \int_{a<t_1<t_2<b}dY_{t_1}\otimes dY_{t_2},\ldots\right).
  \]
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.30\textwidth}
      \textbf{Level 1}\par
      Net displacement
    \end{column}
    \begin{column}{0.30\textwidth}
      \textbf{Level 2}\par
      Ordered pair interactions and signed area
    \end{column}
    \begin{column}{0.30\textwidth}
      \textbf{Higher levels}\par
      Finer ordered interactions
    \end{column}
  \end{columns}
  \textbf{Two constructions used in Experiment A}\par
  Global loss compares one depth-4 signature. Local loss compares depth-2 signatures over a fixed partition, with an anchor for starting position.
  \source{Signature foundations: Chen (1957) [2], Lyons, Caruana and L\'evy (2007) [3], Chevyrev and Kormilitzin (2016) [8]. Project definitions: Notebook 05, Sections 5 and 6}
\end{frame}

\begin{frame}{Signature losses for training}
  Write $\Delta S^{(k)}=S^{(k)}(Z_{\widehat Y})-S^{(k)}(Z_Y)$, with $Z$ the time-augmented output path and $d_Z=3$. Each training loss is a choice of level weight and interval.
  \begin{center}
  \small
  \begin{tabular}{>{\bfseries}p{0.17\textwidth}p{0.44\textwidth}p{0.29\textwidth}}
    \toprule
    Variant & Form & Choice it encodes \\
    \midrule
    Global & $\displaystyle \tfrac1{d_Y}\|\widehat Y(0)-Y(0)\|_2^2+\sum_{k=1}^{4}d_Z^{-k}\|\Delta S^{(k)}\|_2^2$ & Level weighted by coordinate count alone \\
    Local & $\displaystyle \tfrac1K\sum_{b=1}^{K}\sum_{k=1}^{2}d_Z^{-k}\|\Delta S^{(k)}_{I_b}\|_2^2$, $K=10$ & Features attached to coarse time location \\
    Refined local & Same with $K=100$ and factor $(K/K_0)^{2k}$ & Homogeneity correction, so block count alone changes nothing \\
    \bottomrule
  \end{tabular}
  \end{center}

  \vfill
  Anchor terms appear because signatures use increments and are blind to a constant shift. Level weighting is an open choice: signature theory fixes none of these, so levelwise value and gradient are audited before any comparison.
  \source{Definitions and audit: Notebook 05, Sections 4, 6 and 22}
\end{frame}

\begin{frame}{Signature discrepancies for measurement}
  Study C trains nothing, so the same features can be weighted by observed variation rather than by convenience.
  \begin{center}
  \small
  \begin{tabular}{>{\bfseries}p{0.19\textwidth}p{0.42\textwidth}p{0.29\textwidth}}
    \toprule
    Variant & Form & Choice it encodes \\
    \midrule
    Variance normalised & $\displaystyle \sum_{k=1}^{4}\|\Delta S^{(k)}\|_2^2\big/\!\left(d_Z^{k}(q_k^2+\delta)\right)$ & Levels balanced by Brownian variation $q_k$ measured on training streams \\
    Aligned and offset local & Depth two over 128 blocks of 16 increments, and the same shifted by 8 & Isolates partition placement against the message \\
    Response derived & $\displaystyle \sum_{k=1}^{L}r^{k}\|\Delta S^{(k)}\|_1$, $r\in\{0.5,1,2\}$ & $r$ bounds one-step response of a linear controlled system \\
    \bottomrule
  \end{tabular}
  \end{center}

  \vfill
  Response weight $r^k$ is not a convention. A level-$k$ term of a linear controlled response carries $k$ coefficient matrices, so bounding each by $r$ bounds that term by $r^k$, and sweeping $r$ asks how much high-level weight a message needs before it is visible.
  \source{Notebook 07, Section 9. Response bound: Ferrucci, Perr\'ee and Lyons (2026) [10]}
\end{frame}

\begin{frame}{Three studies}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.31\textwidth}
      \textbf{A. Fixed target}\par
      One analytic target path, fitted repeatedly. No input variation and no generalization, so a difference between fitted paths comes from capacity, optimizer or loss.
    \end{column}
    \begin{column}{0.31\textwidth}
      \textbf{B. Learned operator}\par
      Many Brownian drivers with paired OU responses, held-out test paths. Adds generalization and causality to the same loss comparison.
    \end{column}
    \begin{column}{0.31\textwidth}
      \textbf{C. Message sensitivity}\par
      No model and no training. Perturb a stream by a known amount and measure how far each discrepancy moves.
    \end{column}
  \end{columns}

  \vfill
  \textbf{Reason for keeping C separate}\par
  In A and B a loss reaching a poor fit is ambiguous between a representation that ignores the feature and an optimizer that failed to minimize its own objective. Both happened: global-signature training in A finishes worse on its own discrepancy than a pointwise fit. Study C removes optimization entirely, so its answer describes the representation alone.
  \source{Notebooks 05, 06 and 07}
\end{frame}

\begin{frame}{Experiment A: fixed target}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.51\textwidth}
      \textbf{Controlled Neural ODE fit}\par
      Fit one fixed analytic two-dimensional target path:
      \[
        \dot z_\theta(t)=f_\theta(t,z_\theta(t)),
        \qquad \widehat Y_\theta(t)=g_\theta(z_\theta(t)).
      \]
      \begin{itemize}
        \item 64 target observations
        \item uniform or clustered observation times
        \item restricted or expressive model capacity
        \item 3 paired seeds and 10,000 Adam updates
      \end{itemize}
    \end{column}
    \begin{column}{0.44\textwidth}
      \textbf{Reason for the fixed target}\par
      Input variation and generalization are removed. Differences between fitted paths come from model capacity, optimization and training loss.

      \textbf{Matched comparison}\par
      Target, initialization, optimizer budget and model family remain fixed within each group. Only training loss changes.

      Evaluation uses a dense 1,025-point grid and common metrics.
    \end{column}
  \end{columns}
  \source{Procedure: Notebook 05, Sections 3 to 9. Neural ODE model: Chen et al. (2018) [4]}
\end{frame}

\begin{frame}{Experiment B: Brownian driver to OU response}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.50\textwidth}
      Brownian driver $W$ determines an Ornstein--Uhlenbeck response
      \[
        dY_t=-\lambda Y_t\,dt+\sigma\,dW_t,
        \qquad Y_0=0.
      \]
      A Neural CDE learns the whole map $W\mapsto Y$
      \[
        dh_t=f_\theta(h_t)\,d\widetilde X_t,
        \qquad \widehat Y_t=g_\theta(h_t).
      \]
      Control $\widetilde X_t=(t,W_t)$ is the driver augmented by time.
    \end{column}
    \begin{column}{0.44\textwidth}
      \textbf{Matched study}\par
      \begin{itemize}
        \item 512 train, 128 validation and 256 test paths
        \item 64 target times per response
        \item uniform or clustered target sampling
        \item 3 seeds per primary loss
      \end{itemize}

      \textbf{Purpose}\par
      Test whether the sampling mechanism persists when one model learns across many input and response paths.
    \end{column}
  \end{columns}
  \source{Procedure: Notebook 06, Sections 2 to 5. Neural CDE model: Kidger et al. (2020) [5]}
\end{frame}

\begin{frame}{Experiment B: procedure}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.47\textwidth}
      \textbf{Paired generation}\par
      One draw of standard-normal increments produces both the Brownian driver and, through Euler--Maruyama, its OU response. Target is therefore the response to \emph{that} driver, not an independent OU path.

      \textbf{Causal model}\par
      One RK4 step per interval integrates $dh=f_\theta(h)\,d\widetilde X$, so the output at time $t$ depends only on driver increments before $t$.
    \end{column}
    \begin{column}{0.47\textwidth}
      \textbf{Acceptance before comparison}\par
      Gates run before any loss comparison: the generator reproduces its own Euler recurrence exactly; perturbing the driver after the midpoint leaves earlier output unchanged and later output changed; every parameter receives finite gradient; data, initialization, target times and batch order all reproduce by fingerprint.

      \textbf{Matched runs}\par
      Within a seed and condition, every loss shares inputs, targets, initialization and batch order. Only the loss changes.
    \end{column}
  \end{columns}
  \source{Procedure and acceptance: Notebook 06, Sections 2 to 6. Generator: brownian\_ou\_pairs in src/pathloss/datasets.py}
\end{frame}

\begin{frame}{Experiment C: rough-path streams}
  Elapsed-time weighting changes where coordinate error counts. It cannot measure information absent from coordinate values.
  Each supplied stream contains 2,048 step-two increments in four dimensions:
  \[
    \mathbf X_j=(a_j,A_j),
    \qquad a_j\in\mathbb R^4,
    \quad A_j\in\Lambda^2\mathbb R^4.
  \]
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.46\textwidth}
      \textbf{First level $a_j$}\par
      Four coordinate increments. Their cumulative sum gives the visible piecewise path.
    \end{column}
    \begin{column}{0.46\textwidth}
      \textbf{Second level $A_j$}\par
      Six L\'evy-area coordinates. They record within-step order and affect rough differential equation responses.
    \end{column}
  \end{columns}
  Independent Gaussian coordinate increments do not determine the correct joint L\'evy-area law. The supplied simulation includes both levels.
  \source{Data specification: Notebook 07, Sections 3 and 4. Brownian area simulation: Wiktorsson (2001) [6], Foster and Habermann (2023) [7]}
\end{frame}

\begin{frame}{Experiment C: procedure}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.47\textwidth}
      \textbf{Two readings}\par
      Paired: compare each modified stream against its own unmodified original, and normalise by the median distance between two independent streams, so a value of one means the message is as large as ordinary Brownian variation.

      Detection: hand a classifier one stream and ask whether it is modified, with originals and modifications drawn from disjoint underlying paths.
    \end{column}
    \begin{column}{0.47\textwidth}
      \textbf{Controls fixed in advance}\par
      Amplitude grid, message support, discrepancy definitions and split are frozen before results. A second 10,000-stream ensemble stays untouched until every choice is fixed, then repeats the transitions.

      \textbf{Independent verification}\par
      RoughPy reproduces the step-two signatures of original and modified streams to $10^{-9}$, so the perturbation is checked against a library outside this project.
    \end{column}
  \end{columns}

  \vfill
  Amplitude zero is a null control: it must leave every stored coordinate unchanged bit for bit and every discrepancy at zero.
  \source{Notebook 07, Sections 7, 8, 11 and 12}
\end{frame}

\begin{frame}{Message construction}
  A 16-increment block at the stream midpoint receives a message of normalized size $\rho$.
  \[
    b_r=\rho\sigma_1 s_r u,
    \qquad B_r=\rho\sigma_2 s_r v,
    \qquad
    \rho\in\left\{0,\tfrac1{16},\tfrac18,\tfrac14,\tfrac12,1,2,4\right\}.
  \]
  \small
  Scales $\sigma_1,\sigma_2$ are training-set standard deviations of first- and second-level increments. Fixed directions $u\in\mathbb R^4$ and $v\in\Lambda^2\mathbb R^4$ select one coordinate at each level, and $s_r$ is the template below.
  \begin{tabular}{>{\bfseries}p{0.20\textwidth}p{0.31\textwidth}p{0.39\textwidth}}
    \toprule
    Message & Modified component & Intended probe \\
    \midrule
    Increment & $a_j$ only & Coordinate displacement \\
    Area & $A_j$ only & Hidden second-level information \\
    Combined & $a_j$ and $A_j$ & Mixed-level sensitivity \\
    \midrule
    Net template & $s_r=1$ & Basic response to accumulated change \\
    Balanced template & Eight $+1$, then eight $-1$ & Local order with zero direct sum \\
    \bottomrule
  \end{tabular}
  \source{Message construction and training-only scales: Notebook 07, Sections 5 and 6}
\end{frame}

\begin{frame}{Experiment A: derivative supervision}
  \begin{columns}[T,onlytextwidth]
    \begin{column}{0.52\textwidth}
      \textbf{$H^1$ result}\par
      $H^1$ training gives the best general errors in all 6 groups at update 1,000 and 5 of 6 groups at update 10,000.
      It directly penalizes velocity error, so it resolves the target's short oscillatory burst efficiently.
    \end{column}
    \begin{column}{0.42\textwidth}
      \textbf{Interpretation limit}\par
      This target is analytic and its derivative is known. Brownian paths are almost surely outside $H^1$, so the same supervision is unavailable for rough stream tasks.
    \end{column}
  \end{columns}

  \vfill
  Smooth targets can reward derivative-aware losses more than generic structural summaries. Signature losses are compared against this control rather than against MSE alone.
  \source{Results: Notebook 05, Sections 17 and 21. Sobolev viewpoint: Ramsay and Silverman (2005) [1]}
\end{frame}

\begin{frame}{Experiment B: optimizer stability}
  \begin{center}
    \includegraphics[width=\linewidth]{assets/ou_signature_histories.png}
  \end{center}

  \vfill
  Both signature objectives reach much lower training loss early, then rise. Final-to-best training-loss ratios are 28.4, 28.5 and 2.32 for the global loss. Terminal fits therefore record optimizer behaviour rather than a path the geometry prefers, so every signature claim in this project is stated at a fixed budget.

\begin{frame}{Validation checks for Brownian messages}
  \small
  \begin{itemize}
    \item Acceptance tests verify shape, finite values, basis dimensions, Brownian scaling, message support and zero-message identity.
    \item RoughPy independently verifies original and modified step-two signatures to tolerance $10^{-9}$.
    \item Main study uses 10,000 supplied streams. Confirmation uses a disjoint 10,000-stream ensemble.
    \item All 29 valid main detection transitions reappear in confirmation. Twenty-three use the same amplitude, four move by one tested amplitude, and two response-derived thresholds move by two.
    \item A main raw-area null control failed and passed on confirmation. Main thresholds involving that feature are withheld.
  \end{itemize}
  \textbf{Interpretation rule}\par
  Confirmation establishes repeatability of threshold order on another finite ensemble. It does not create a universal detection boundary.
  \source{Notebook 07, Sections 9 to 12}
\end{frame}
